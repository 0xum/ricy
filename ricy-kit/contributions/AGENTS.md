# Existing contributions

Read the relevant local README section; consult [COMPONENTS](../../docs/COMPONENTS.md)
to locate ownership/boundaries.
Use [CONTRIBUTION-AUDIT](../../docs/CONTRIBUTION-AUDIT.md) before choosing a
variant: it records current consumers and exceptions within mixed-role folders.
An old build can be historical while its activator/restorer is still required.
The default source checks exclude only the explicit HISTORICAL recipes listed in
[DEVELOPMENT](../../docs/DEVELOPMENT.md#historical-reproduction). README commands
in older variants are reproduction records, not instructions for the current
desktop. Use reordering for the maintained cumulative source and window-fade-expand
for the selected effect; neither choice authorizes activation during cleanup.
Follow the [kit](../AGENTS.md) routing; the future destination does not change
current ownership. Before editing, look for a copy in the transport kit;
do not blindly synchronize trees or copy private profiles. Preserve old variants,
licenses, restorers, and paths between contributions. Validators may depend on
cached sources; read them before running and never confuse applying/installing
with validating.
