# Contribuições existentes

Leia o trecho pertinente do README local; consulte [COMPONENTS](../../docs/COMPONENTS.md)
se precisar localizar ownership/fronteiras.
Aplique o roteamento do [kit](../AGENTS.md); o destino futuro não muda ownership atual.
Antes de editar, procure cópia no kit de transporte; não sincronize árvores
cegamente nem copie perfis privados. Preserve variantes antigas, licenses,
restauradores e paths entre contribuições. Validadores podem depender de fontes
em cache; leia-os antes de rodar e nunca confunda aplicar/instalar com validar.
