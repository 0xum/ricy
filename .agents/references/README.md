# Carregamento progressivo de evidências

1. Siga o roteamento por consequência de [AGENTS](../../AGENTS.md).
2. Leia o trecho pertinente do README local; use
   [COMPONENTS](../../docs/COMPONENTS.md) se precisar localizar ownership/fronteiras.
3. Consulte [IDENTIDADE-VISUAL](../../docs/IDENTIDADE-VISUAL.md) somente para visual,
   [REINSTALAR](../../docs/REINSTALAR.md) para transporte/instalação e trechos de
   [ricy.md](../../docs/ricy.md) por assunto/data para histórico.
4. Reproduza evidência com os comandos de [DEVELOPMENT](../../docs/DEVELOPMENT.md).

Não copie os registros completos para skills, não carregue estado privado sem
necessidade e não trate validações de sessões antigas como execução atual.
