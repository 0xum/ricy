# Progressive loading of evidence

1. Follow the routing as a result of [AGENTS](../../AGENTS.md).
2. Read the relevant section of the local README; use
   [COMPONENTS](../../docs/COMPONENTS.md) If you need to locate ownership/borders.
3. See [VISUAL IDENTITY](../../docs/VISUAL-IDENTITY.md) for visual only,
   [REINSTALL](../../docs/REINSTALL.md) for transport/installation and stretches of
   [ricy.md](../../docs/ricy.md) by subject/date for history.
4. Play evidence with the commands of [DEVELOPMENT](../../docs/DEVELOPMENT.md).

Do not copy the complete records to skills, do not load private status without need, and do not treat validations of old sessions as current execution.
