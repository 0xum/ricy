# themes

The canonical consumable visual source is [tokens](tokens/README.md), using
existing values. Do not duplicate palette, radii, motion, or typography in new
handwritten consumers. Retained legacy/transport snapshots are provenance, not
second editable authorities. Distinguish shell, KDE, Dolphin and terminal
adaptations and preserve theme licenses.

Visual/UI: [DESIGN-SYSTEM](../docs/DESIGN-SYSTEM.md); adaptations between components
or states/materials: [visual-development](../.agents/skills/visual-development/SKILL.md).
If login, locking, or fallback usability is affected, read [RECOVERY](../docs/RECOVERY.md).
